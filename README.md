# Micro SaaS Lab

Astro static validation site for one tool: AI quote drafts for small service businesses (in development, not available). Waitlist form is disabled until a form endpoint is chosen.

    npm install && npm run build

Config: `astro.config.mjs` (site/base via SITE_URL, BASE_PATH). Content: `src/content/pages/`. Routine: `PLAYBOOK.md`. Status: `STATUS.md`.
